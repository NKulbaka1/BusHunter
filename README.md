# BusHunter

## Запуск
Для начала работы нужно склонировать проект:
```sh
git clone https://github.com/NKulbaka1/BusHunter.git
```
Приложение работает в докере, поэтому для запуска достаточно одной команды:
```sh
docker compose up --build
```
После запуска описание API можно найти в [Swagger](http://localhost:8080/swagger-ui/index.html#/). Оттуда же можно поделать запросы.

# Функционал

- Аутентификация и авторизация пользователей через JWT токены (access + refresh)


- Для клиентов: поиск доступных билетов по фильтрам, выкуп билетов, просмотр перевозчиков и маршрутов.


- Для админов: те же возможности, что у клиентов + операции создания, редактирования и удаления для сущностей (билеты, маршруты, перевозчики).

# Особенности

- Купленные билеты кэшируются для каждого пользователя в БД **Redis**. При запросе билетов пользователя, данные достаются из кэша. При обновлении билетов пользователя, данные в **Redis** обновляются.


- Создан отдельный микросервис, который принимает данные о купленных билетах из топика **Kafka** и сохраняет их в свою БД. При покупке билета в основном микросервисе данные билета дополнительно отправляются в этот топик **Kafka**.
